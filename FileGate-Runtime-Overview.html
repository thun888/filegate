启动流程 (Startup)
01
解析命令行参数
读取 -config 标志，默认加载 config.yaml
configPath := flag.String("config", "config.yaml", "Path to config")
02
加载并验证配置
config.Load() — 读取 YAML → 设置默认值 → normalize → validate
cfg, err := config.Load(*configPath)
03
初始化 Server
创建 Router · PolicyEngine · Processor · 后端实例 · 限流器 · Imgproxy 客户端 · 注册路由
srv, err := server.New(cfg)
04
构建路由表
NewRouter() — 将 Namespace → Class → BackendPolicy 映射为 map[string]map[string]Route
GET /fs/:namespace/:class/*path
HEAD /origin/:namespace/:class/*path
05
启动 HTTP 服务
绑定地址并开始监听，等待客户端请求
srv.Run(addr) → Gin ListenAndServe
